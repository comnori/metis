== AsciiDoc 기본 문법

문서 제목에는 `=`, 섹션 제목에는 `==` 기호를 씁니다.
별표는 *굵게*, 밑줄은 _기울임_, 백틱은 `코드` 서식을 적용합니다.

* 줄 앞에 별표와 공백을 넣으면 글머리표 목록이 됩니다.
* 줄 앞에 마침표와 공백을 넣으면 번호 목록이 됩니다.

. 원문을 한 줄 바꿉니다.
. 미리보기에서 결과를 확인합니다.

====

====

== Mermaid 흐름도

`[mermaid]` 아래에 `----` 구분선으로 블록을 시작하고 끝냅니다.
`A[아이디어]` 예제에서 대괄호 안 문구를 바꿔 보세요.

[mermaid]
----
flowchart LR
    A[아이디어] --> B[초안]
    B --> C[검토]
----

== D2 구성도

`[d2]` 블록에서 `이름: 표시할 글자` 형식으로 노드를 정의합니다.
노드를 연결할 때는 `+->+` 기호를 씁니다.
`+app -> db: 조회+` 예제에서 연결선 이름을 바꿔 보세요.

[d2]
----
direction: right
user: 사용자
app: 앱
db: 데이터베이스 {shape: cylinder}
user -> app: 요청
app -> db: 조회
----
