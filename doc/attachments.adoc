= 로컬 첨부파일

문서 도구 또는 명령 팔레트의 **첨부파일 삽입**, 편집기로 파일 드롭, 이미지 붙여넣기를 사용할 수 있습니다.

[mermaid]
----
flowchart LR
    A[파일 선택·드롭·이미지 붙여넣기] --> B[문서 옆 assets에 복사]
    B --> C[편집 버퍼에 표준 AsciiDoc 삽입]
    C --> D[문서 저장]
    C --> E[미리보기 표시·재생]
----

외부 파일은 현재 문서 폴더의 ``assets/``에 복사하고, 작업 공간 내부 파일은 기존 위치를 참조합니다. 같은 이름이 있으면 숫자 접미사를 붙입니다. 이미지 붙여넣기는 PNG로 변환합니다. 원문 삽입은 실행 취소할 수 있지만 이미 복사한 첨부파일은 삭제하지 않습니다. 문서 저장은 별도로 실행합니다.

== 지원 문법

[source,asciidoc]
----
= 첨부 예제
:imagesdir: assets

.스크린샷
image::screenshot.png[화면 설명,640,360]

인라인 image:icon.svg[아이콘,24,24] 이미지입니다.

audio::recording.wav[]

video::demo.webm[poster=poster.png]

link:assets/report.pdf[보고서 열기]
----

[cols="1,1",options="header"]
|===
| 종류 | 미리보기 동작
| 이미지 | 블록·인라인 표시, 크기·대체 텍스트·캡션. SVG는 이미지로 표시
| 오디오·비디오 | 로컬 파일 재생·탐색. 코덱 지원 여부는 Electron과 OS에 따라 달라짐
| PDF·일반 문서·압축파일 | 링크 클릭으로 OS 기본 앱 실행
| 실행 파일·스크립트·바로가기·HTML·SVG·미분류 파일 | 링크를 열 때 OS 파일 탐색기에서 위치 표시
|===

``imagesdir``는 Asciidoctor HTML 변환 결과에 따라 이미지·오디오·비디오와 poster에 적용합니다. 포함 문서의 이미지도 상위 문서로 변환된 경로를 기준으로 찾습니다. 변환된 미디어 경로와 일반 링크는 상위 문서 폴더 기준 상대 경로를 사용합니다. 경로의 한글과 공백을 지원하며 삽입 시 필요한 문자를 인코딩합니다.

== 제한과 오류 처리

* 로컬 첨부 미리보기는 작업 공간 내부 파일만 표시합니다. 원격 미디어, 절대 경로, 심볼릭 링크·junction은 지원하지 않습니다. YouTube는 별도의 link:preview-extensions.adoc[YouTube 영상 확장]에서 지원합니다. Vimeo는 지원하지 않습니다.
* 미디어 자동 재생은 하지 않으며 재생 컨트롤을 제공합니다. 원문의 자동 재생 옵션은 그대로 보존됩니다.
* 미디어 삽입 시 ``imagesdir``는 로컬 상대 경로여야 합니다. 원격 ``imagesdir``에서는 복사한 파일 위치를 안내하고 미디어 매크로를 삽입하지 않습니다.
* 누락 파일·접근 실패는 첨부 위치에서 안내합니다. 재생 불가 코덱은 **첨부 열기**, 기본 앱 실패는 **파일 위치 열기**로 처리할 수 있습니다.
* 파일 선택·드롭은 요청당 최대 50개, 외부 파일은 개당 1 GiB, 클립보드 PNG는 32 MiB까지 지원합니다. 미리보기 리소스는 한 번에 서로 다른 대상 1,000개까지 등록합니다.
* 첨부는 문서 검색·백링크 색인 대상이 아닙니다. 파일 이동 기능은 첨부 상대 경로를 자동 보정하지 않으므로 이동 후 경로를 확인하세요.
* PDF는 내장 뷰어로 표시하지 않습니다. 첨부파일이 없어도 문서 원문을 편집하고 저장할 수 있습니다.

== 검증

``npm run check``, ``npm run test:desktop:core``, ``npm run test:attachments``로 확인합니다. 패키지 검증은 ``node scripts/attachments-smoke.mjs <패키지 실행파일>``을 사용합니다. GUI 검증은 PNG·SVG 표시, WAV·VP8 WebM 재생·탐색, 파일 열기 요청과 실패 대안, 삽입·실행 취소·PNG 붙여넣기·저장을 검사합니다. OS 기본 앱 호출은 자동 테스트에서 대체합니다.

실행 결과와 화면은 ``.pre04-runs/attachments-*/``에 기록합니다. 다른 OS와 코덱의 지원을 이 결과로 일반화하지 않습니다.
